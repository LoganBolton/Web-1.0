# Weave evals

`questions.jsonl` has **224 questions**, each with one short, objective answer that can be
checked automatically.

| Difficulty | Count | What it means |
|---|---|---|
| easy | 90 | One page. The answer is stated plainly and is easy to reach by search or obvious links. |
| medium | 77 | One or two hops, or a table lookup, a date or unit conversion, a script-driven search box, or a site the search engine does not index. |
| hard | 57 | Three or more hops, conflicting or stale sources, answers only in images, forms and calculators, logins, archived or hidden pages, or arithmetic across sites. |

There is no multiple choice. Answers are names, numbers, dates, times, codes, or short phrases.
The world's "today" is **Loomday, 17 Gale 412 CR**, so questions about the current state of
things (standings, open recalls, prices) are fixed in time and do not drift.

## Question format

```json
{
  "id": "h014",
  "question": "A Noticeboard ad sells a Copper Kettle gift card as 'worth 25 cr'. What is that card's real balance?",
  "answer": "3.00 cr",
  "accept": [],
  "kind": "number",
  "tolerance": 0.0,
  "difficulty": "hard",
  "modality": "interaction",
  "hops": 2,
  "topic": "scams",
  "evidence": [{"url": "http://noticeboard.fol/for-sale/", "text": "Copper Kettle gift card"}],
  "steps": [["goto", "http://copperkettle.ves/gift-cards/"], ["fill", "#gc", "CK-3500-1400"], ["click", "#go"], ["read", "#bal"]],
  "notes": "answer appears only after using the page's form"
}
```

* `kind` is `text`, `number`, or `set` (a list whose order does not matter).
* `modality` says how the answer is found: `text`, `image` (only in a picture), `interaction`
  (only after using a form or logging in), or `source` (only by reading page source).
* `evidence` and `steps` are for graders and question writers. **Do not show them to the agent.**
  Give the agent only `question`, plus a starting page such as `http://morrow.ves/`.

## Grading

Write predictions as JSON lines, `{"id": "e001", "answer": "..."}`, then:

```bash
python evals/grade.py predictions.jsonl              # lenient: answer may be a short sentence
python evals/grade.py predictions.jsonl --strict     # answer must be just the answer
python evals/grade.py predictions.jsonl --show-wrong
```

Scores are reported overall, by difficulty, and by modality. Numbers are compared as numbers
(commas, units and currency ignored, `2¼` and `2 1/4` understood, `4.2 million` understood),
within the question's tolerance. Text is compared after normalising case and punctuation,
against the answer and its accepted variants. In lenient mode an answer may also contain the
gold answer inside a short sentence, but padding a reply with many candidates does not score.

## How the questions are made and checked

The questions are generated by `othernet/evalgen.py` from the same world data the sites are
rendered from, then checked against the built Weave:

```bash
python -m othernet.build                 # build the Weave
python -m othernet.evalgen               # regenerate questions.jsonl; fails if any answer is not where it should be
python -m othernet.serve &
node tools/verify_interactive.js         # replays the steps of every interactive question in a browser
```

Every `evidence` text must appear in its page, so no question survives unless an agent could
actually find its answer. The build is deterministic, so the questions and the Weave stay in
step. See `docs/WORLD.md` for the storylines behind the hard questions.
