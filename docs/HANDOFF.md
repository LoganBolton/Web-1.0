# Handoff notes

Where the project stands and what is left to do. Written when work moved from a cloud
session to a laptop.

## What this is

WebSim is a fictional internet for testing web agents. The world is Averra and its internet
is the Weave. There are 54 interlinked sites and about 8,800 pages, all generated by a
deterministic Python generator (`othernet/`, standard library only). Because the world
does not exist, agents cannot lean on what they already know about the real web. The
"present day" in Averra is Loomday, 17 Gale 412 CR.

## What was built, in order

1. **The Weave** (`othernet/`). World simulation (calendar, people, companies, history,
   markets, sport, weather, news), 54 site modules, and a server (`python -m othernet.serve`)
   that works as an HTTP proxy, by `*.localhost` subdomains, or by Host header. It is hard on
   purpose, with partial search, conflicting sources, paywalls, logins, forms, archives,
   answers that exist only in images, and so on. See `README.md` and the spoiler guide
   `docs/WORLD.md`.
2. **Eval questions** (`evals/`). 224 questions with objective answers and no multiple
   choice (90 easy, 77 medium, 57 hard). They are generated by `othernet/evalgen.py` and each
   is checked against the built Weave. `evals/grade.py` scores predictions.
   `tools/verify_interactive.js` replays the interactive ones in a browser.
3. **Agent harness** (`harness/`). Runs Codex (or another Harbor agent) on the questions
   through Harbor with no way to cheat. See `harness/README.md`. In short, each trial has
   * `main`, the agent's container, with Codex preinstalled and no repo files. Its network
     allows only the model API and the browser.
   * `browser`, Playwright MCP plus Chromium over HTTP. It is the agent's only route to the
     Weave. At startup it deletes its internet route and drops privileges.
   * `weave`, the site server, on a private network only the browser can reach.
   * a separate grader container with no network, built from the task's `tests/`. It only
     sees `/logs/artifacts/answer.txt`.
   * `codex-job.yaml` turns off Codex's web search, which runs on OpenAI's side and could
     otherwise find this public repo's answer file.

## What was verified in the cloud session

* Harbor's oracle agent scored 6/6, so the grading path works.
* `harness/probe_agent.py` tries to cheat from inside the agent's container. It found no
  answer files and could not reach the site server, GitHub or the grader. The browser could
  not reach the real internet even through its code-running tool. The browser did load the
  Weave and return screenshots.
* Codex 0.157.1, driven by a fake model server, listed the browser tools, called
  `browser_navigate` successfully, and sent screenshots back to the model as images.
* Bug found and fixed there. The MCP server (Node) closed idle keep-alive connections after
  5 seconds, and Codex reused them, so tool calls after a pause failed.
  `harness/images/browser/keepalive.cjs` raises the timeout.

## Not done yet

* **No real Codex run.** The cloud container intercepted HTTPS, so Codex could not talk to
  OpenAI. The first real run should happen on the laptop.
* **Repo name.** It lives at `LoganBolton/Web-1.0`. The plan was to rename it to WebSim in
  GitHub Settings (the code and README already say WebSim).
* **Two wording blemishes in the questions**, "Bazaar Holdings's" and "A History of
  Emberly II II". Fix in `othernet/evalgen.py` and regenerate.
* macOS Docker Desktop may lack the kernel nftables `fib` support that Harbor's egress
  control needs. OrbStack or a Linux host works.

## First steps on a new machine

```bash
uv tool install harbor                  # Harbor needs Python 3.12+
bash harness/build_images.sh
python harness/make_tasks.py --limit 10
harbor run -p harness/tasks -a oracle -e docker -y                                # expect 100%
PYTHONPATH=harness harbor run -p harness/tasks/e001 -a probe_agent:ProbeAgent -e docker -y   # expect "PROBE OK"
export OPENAI_API_KEY=sk-...
harbor run -c harness/codex-job.yaml -m openai/<model>
python harness/score.py --show-wrong
```

## House style for anything written for the user

No em dashes, no semicolons, no colons in prose, and none of the usual AI writing cliches
such as "it's not X, it's Y".
